## 概述

Real Deep Research (RDR) 是一个系统性的框架，用于分析研究格局、识别新兴趋势、发现跨领域机会，并为新研究提供具体的起点。RDR的核心是一个基于嵌入的分析管道，由四个主要组件构成：**数据准备**、**内容推理**、**内容投影**和**嵌入分析**。

## 方法实现

### 1. 数据准备

#### 论文收集（选择）
RDR从顶级计算机视觉、机器人学和机器学习会议（CVPR、ECCV、ICCV、CoRL、RSS、ICRA、NeurIPS等）以及行业研究平台（Nvidia、Meta、OpenAI）收集论文。这个语料库提供了基础模型和机器人学研究领域的全面概述，突出了关键技术进展、现有挑战和未来研究方向。

**实现：**
- **会议爬虫**：`/venue/`目录中的各个会议模块（如`rss22.py`、`cvpr.py`、`icra.py`）直接从会议网站爬取论文标题、作者、摘要和PDF链接
- **期刊爬虫**：`science.py`、`nature.py`、`quantum.py`等模块使用OpenAlex API获取科学期刊论文
- **行业爬虫**：`meta.py`、`nvidia.py`从行业平台收集研究

#### 领域筛选
为确保收集的论文与研究范围相关，RDR采用领域筛选过程，使用高效的LLM和预定义提示来识别与基础模型和机器人学相关的论文。

**基础模型定义**："基于大量数据训练的深度学习模型（特别是Transformer模型），能够拟合广义事实现实。这些模型通常作为多领域各种下游任务的通用骨干。"关键指标包括大型多模态模型（LMM）和大型语言模型（LLM）。

**机器人学定义**："配备输入传感器和机械运动学硬件系统，能够产生关节运动。这些系统由基于学习的算法控制，这些算法有助于实现从传感器输入到执行器输出的自动化或鲁棒映射。"关键指标包括机器人语境中的强化学习和物理系统中的模仿学习。

筛选后，得到的论文集合P'属于基础模型领域（$D_f$）、机器人学领域（$D_r$）或两者兼有。形式上：$P' = \{p | p \in D_f \cup D_r\}$。

**实现：**
- 筛选后的数据集存储在`/dataset/`目录中的`*_filter1.json`文件中
- 每个筛选后的论文包含布尔标志`is_foundation_model`和`is_robotics`及推理原因
- 来自`meta_filter1.json`的示例：
```json
{
  "is_foundation_model": true,
  "foundation_reason": "该论文使用视觉语言模型（VLM），这是基础模型研究的关键指标...",
  "is_robotics": false,
  "robotic_reason": "该论文专注于视觉语言模型的统一基准，没有硬件连接..."
}
```

### 2. 内容推理

#### 定义研究视角
针对筛选后的论文集合P'，RDR进行深入分析以确定每篇论文的具体定位。在基础模型和机器人学领域专家的指导下，RDR定义了与既定领域结构、新兴趋势和不断发展的知识相符的视角。除了预定义的视角，RDR管道还支持用户自定义视角，以适应新的研究问题。

#### 基础模型视角
RDR通过五个基本视角系统地分析基础模型的发展：输入（I）、建模（M）、输出（O）、目标（W）和学习策略（R）。

- **输入（I）**：基础模型的输入处理通常涉及原始数据和分词程序。标准输入源包括图像、视频、音频、激光雷达等，通过转换和神经网络进行分词。
- **建模（M）**：建模部分负责从输入中提取关键知识，进行推理，并解码到输出空间。
- **输出（O）**：任务决定解码空间，这是将潜在表示解码为用于损失计算或最终交互的输出的最后一步。
- **目标（W）**：为了使基础模型与相应的输入和输出相匹配，给定模型架构受学习目标的约束，使其模型分布与任务给定的转换对齐。
- **策略（R）**：策略是关于如何通过输入、输出和目标来调整模型权重的"食谱"，它控制训练阶段、收敛速度和更新参数。

形式上：$D'_f = \bigcup_{p \in P'} F(p)$，其中$F(p) = \text{LLM}(p | \text{I, M, O, W, R})$。$D'_f$表示给定论文在基础模型研究上的视角投影。

#### 机器人学视角
机器人学研究的核心视角转向强调真实世界环境中的硬件和交互。RDR定义了五个关键视角来映射每篇论文在更广泛的机器人应用领域中的位置：输入传感器（S）、物理本体（B）、关节输出（J）、动作空间（A）和环境（E）。

- **输入传感器（S）**：输入传感器是测量物理量或环境条件的硬件设备，并将其转换为机器人控制系统可以处理的数字信号。
- **物理本体（P）**：机器人学中的物理本体指能够与环境进行物理交互的机械结构和架构。
- **关节输出（J）**：关节输出指机器人关节因执行电机命令而产生的物理运动或配置。
- **动作空间（A）**：动作空间是机器人在给定语境中可以执行的所有允许动作的集合，范围从低级关节命令到高级行为。
- **环境（E）**：环境包括机器人操作的物理空间，其特点是空间布局、结构特征和上下文元素。

形式上：$D'_r = \bigcup_{p \in P'} F(p)$，其中$F(p) = \text{LMM}(p | \text{S, B, J, A, E})$。$D'_r$表示给定论文在机器人学研究上的视角投影。

#### 提示工程
RDR使用特定的提示来从论文内容中提取每个视角的信息。例如，提示会要求分析论文内容，并识别出定义好的各个视角，并以指定格式返回答案。

### 3. 内容投影

#### 自然语言到潜在空间投影
RDR的目标是将通过定义视角从研究论文中提取的自然语言描述投影到一个信息丰富的潜在空间中。这一投影使得能够对基础模型和机器人学领域的当前研究进行大规模分析，并揭示潜在的未来研究方向。

RDR利用预训练的嵌入基础模型G将$D'_f$（经过处理的基础模型论文内容）和$D'_r$（经过处理的机器人学论文内容）从自然语言空间投影到更抽象的嵌入空间。该嵌入模型将文本映射到高维向量空间，其中语义相似的概念占据相近的区域。

形式上，对于任何文本片段$x \in D$，其嵌入计算为$v_x = G(x) \in R^d$。

核心假设是，通过这种视角感知的嵌入过程投影论文内容，并在高维流形中分析它们，可以通过系统可视化和聚类分析揭示有意义的模式、研究趋势和文献中潜在的空白。

### 4. 嵌入分析

#### 结构化理解
嵌入分析的目标是结构化对先前提取的嵌入的理解。嵌入分析的管道包含三个组件：
- 对提取的嵌入进行聚类，并分析每个集群的主要概念
- 结构化每个集群的概念，以形成一个信息丰富的表格
- 根据结构化理解，追溯到参考论文

#### 嵌入聚类
RDR首先嵌入每篇论文以获得其向量表示V，并将语料库分成k个集群。从每个集群中，随机抽取50篇论文，并将其文本输入到基于推理的模型中，结合以下提示：

"请将以下内容总结成三个不同的关键词：这里有一个示例输出：'关键词1、关键词2、关键词3'。输出应简短精确，每个论文只有一个输出。"

模型返回三个紧凑的关键词，捕捉集群的核心主题，为每篇论文提供集群标签和一套可解释的关键词，以便后续分析。

#### 结构化调查
在有了聚类嵌入及其相关主题关键词后，下一步是为给定的研究领域生成结构化调查。RDR利用03语言模型，使用聚类关键词作为提示来指导最终调查内容的制定。

将聚类结果纳入提示确保生成文本以实际研究格局为基础，从而提高连贯性和相关性。RDR使用以下提示生成最终输出：

"这些是科学论文通过摘要内容聚类后的关键词，但是它们是模糊的，内容可能在集群之间重叠，你能根据以下标准以更结构化的方式为受众总结信息吗：..."

## 项目结构

```
rdr-scripts/
├── dataset/                    # 收集和筛选的论文数据集
│   ├── *.json                 # 按会议/年份的原始论文集合
│   └── *_filter1.json         # 经过领域分类的筛选论文
```

## 使用方法

1. **数据收集**：运行`/venue/`目录中的各个会议脚本以收集论文
2. **领域筛选**：应用筛选逻辑将论文分类到基础模型和机器人学领域
3. **内容分析**：使用基于视角的推理提取结构化信息
4. **嵌入投影**：将处理后的内容投影到嵌入空间
5. **聚类分析**：对嵌入进行聚类和主题分析
